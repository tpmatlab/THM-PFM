# THM-PFM Supplementary Code

Repository containing the computational implementation of the model presented in:

> "An Efficient Open-Source Thermohygromechanical Phase-Field Model for Explosive Spalling in Refractory Castables"

The code is implemented in Python using [FEniCS](https://fenicsproject.org/) and contains the
simulations and material properties used to investigate the drying of refractory castables using a phase-field model..

In case of use of this code, please cite the corresponding publication.

### Simulation cases

- `case_1_column_ATS.py`: Column simulation using adaptive time stepping (ATS).
- `case_1_column_fixed_step.py`: Column simulation using a fixed time step.
- `case_1_column_substepping.py`: Column simulation using time-step substepping.
- `case_2_wall_uniform_alpha_0_ATS.py`: Wall simulation with uniform properties
  and $\alpha=0$, using adaptive time stepping.
- `case_3_wall_uniform_biot_0_ATS.py`: Wall simulation with uniform properties
  and $\mathrm{Bi}=0$, using adaptive time stepping.
- `case_4_wall_uniform_ATS.py`: Wall simulation with uniform material properties
  using adaptive time stepping.
- `case_5_wall_flame_ATS.py`: Wall simulation considering flame heating using
  adaptive time stepping.
- `case_6_wall_mw_ATS.py`: Wall simulation considering microwave heating using
  adaptive time stepping.

### Material properties

- `material_properties.py`: Material properties used in the standard simulations.
- `material_properties_alpha_0.py`: Material properties used for the
  $\alpha=0$ simulation.
- `material_properties_biot_0.py`: Material properties used for the
  $\mathrm{Bi}=0$ simulation.

### Utilities

- `utils.py`: Auxiliary functions used by the simulation cases.

## How to run the simulations

The simulations can be executed directly from the root directory of this
repository.

For example, to run the column case using adaptive time stepping:

```bash
python3 ./case_1_column_ATS.py
```

The results generated by each simulation are saved in the a folder named `results` 
within the root directory of the repository.

The resulting files can be loaded using ParaView or further processed using
Python.

### Adaptive time stepping

The simulations whose filenames contain `_ATS` use an adaptive time-stepping
procedure. The pseudo-time increment is automatically adjusted according to the
evolution of the numerical solution.

For comparison, `case_1_column_fixed_step.py` uses a prescribed fixed time
step, while `case_1_column_substepping.py` uses time-step substepping.

## Dependencies

The following software and Python packages are required:

- Python 3.7+
- NumPy
- FEniCS 2019.1.0

The simulations were developed and tested using the software versions listed
above. Different versions may require modifications to the code.
